Three things it does without being asked

Tells you what to do first

One recommendation at the top of the day with the reason attached. A review that has blocked two people beats an empty inbox.

Writes your work log

Pull requests you merge are summarised into a sentence each as they happen, so standups, one-to-ones and reviews are already written when you need them.

Answers about your own week

“What did I ship?” “What is waiting on me?” Grounded in your log, with the sources listed, answered by a model on your machine.

why local matters here

Your work log is the most sensitive document you own.

It is every unshipped feature, every slipped date and every awkward thread, in one place. Chief keeps it in a SQLite file in your own app directory and asks a model on the same machine to read it. There is no account, no sync, and no vendor with a copy.

Install the app

Builds for macOS and Windows. The llama.cpp engine is bundled, so there is no separate runtime to install and no installer account.

02

Download a model, once

First run fetches Llama 3.2 3B — about 2 GB, with a progress bar and a resumable download. After that it is yours offline.
